# Projet-pendule-invers-rotatif-
Ce projet vise à modéliser, analyser et contrôler un pendule inversé rotatif à l'aide de techniques de commande numérique. Il comprend la linéarisation du système, la conception d'un contrôleur par retour d'état, ainsi que le développement d'une stratégie de swing-up basée sur l'énergie, suivis d'une validation par simulation et expérimentation
